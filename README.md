# voiceassistweb

Official promotional & news website for **Voice Assistant** — an offline, Bangla-first AAC app for special children, built by the Department of Biomedical Engineering, MIST (mist.ac.bd).

This site is **not** a web version of the app. It promotes the project and publishes updates: device handover events, app releases, and photos/videos of children using the app.

## Stack

Next.js 15 (App Router, TypeScript) · Payload CMS 3 (admin at `/admin`) · PostgreSQL · Tailwind CSS + shadcn/ui · next-intl (English + বাংলা) · Vercel
